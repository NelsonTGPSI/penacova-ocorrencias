# 🌊 Penacova Ocorrências

Aplicação web **full-stack** para registo e gestão de **ocorrências fluviais em Penacova**.

## ⚙️ Tecnologias
- **Backend:** Node.js + Express + Sequelize (PostgreSQL)
- **Frontend:** React + TailwindCSS (PWA)
- **Autenticação:** JWT
- **Implantação:** Docker / docker-compose
- **Exportação:** CSV / PDF
- **Modo Offline:** cache e sincronização
